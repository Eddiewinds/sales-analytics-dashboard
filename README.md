# SalesPulse - Executive Sales Analytics Dashboard

A modern, responsive, single-page sales analytics dashboard built with vanilla HTML5, CSS3, and modern JavaScript.

## Features

- **Executive KPI Cards**: Real-time tracking of Total Revenue, Orders Count, Average Order Value (AOV), and Conversion Rate.
- **Interactive Visualizations (Chart.js)**:
  - Daily & monthly Revenue vs Volume trend lines.
  - Category revenue distribution doughnut chart.
  - Regional performance breakdown bar chart.
  - Ranked leaderboard for top-performing products.
- **Client-Side Persistence**: Fully functional CRUD operations powered by WebStorage (`localStorage`) with sample seed data.
- **Advanced Table Controls**: Real-time debounced search, status and category filtering, and pagination.
- **Exporting**: Instant client-side CSV export of filtered transaction data.
- **Pure Vanilla Implementation**: No backend required, zero dependencies (except Chart.js via CDN), and strictly no CSS variables.

## Getting Started

Simply open `index.html` in any modern web browser or host on any static hosting service (GitHub Pages, Vercel, Netlify).
